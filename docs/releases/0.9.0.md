# Marqov SDK 0.9.0

This release adds provider execution and provenance features, saved-script
platform client helpers, circuit reconstruction fixes, and bounded provider
waits. It pins the maintained `marqov-quantumflow` dependency to **1.0.2**,
including the correction for floating-point roundoff in local sampling.

## Install

```sh
python -m pip install --upgrade "marqov==0.9.0"
```

Python remains >=3.12. Use Python 3.12 for `[all]`, `[rigetti]` and `[pyquil]`:
those optional dependency combinations are not qualified on Python 3.13.
Do not install upstream `quantumflow` alongside `marqov-quantumflow`; both
provide the same import package.

## Highlights

- Local `Circuit.simulate().sample()` works for deterministic states with small
  floating-point overshoot or undershoot. The simulated state stays unchanged;
  zero, nonfinite and materially unnormalized states are refused explicitly.
- Circuit dictionary reconstruction preserves supported imported gates and
  raises `ValueError` for unsupported records or incorrect argument counts.
- Braket XY imports use their own angle. Braket and pyQuil importers refuse
  modifiers they cannot preserve rather than silently changing the circuit.
- PennyLane Lightning and Alice & Bob execution paths, updated Qristal and
  QiliSDK adapters, and richer provider provenance are included. Live remote,
  GPU and hosted runtime qualification remain separate.
- Braket, IonQ, Azure and Rigetti interruption paths retain recovery context
  and perform bounded, best-effort cleanup where supported. Rigetti measures
  actual exported wires and rejects incomplete or malformed readout.
- IonQ's explicit v0.4 ideal-simulator route retains original probability
  artifacts and distinguishes probability-derived counts from raw shots.
  Legacy defaults and wire ordering remain unchanged.
- Saved-script platform helpers expose `save_script()`,
  `script_execution_options()`, `analyse_script()` and `submit_script()`.
  Analysis and submission are explicit caller actions. Existing inline and
  managed-native workflow submission APIs remain available.
- Invalid workflow graph/output references fail before execution instead of
  leaving a workflow to fail later. Release publication verifies the built
  wheel before either publisher runs.

## Upgrade notes

Older serialized XY circuits cannot recover an angle lost during import:
re-import them from the original Braket circuit. Unsupported gate modifiers
must be represented with explicit supported gates or decomposed before import.
These refusals replace silent loss of circuit semantics.

Cancellation is a request, not proof that provider execution stopped. Preserve
job identity for recovery; an uncertain submission is not permission to replay
it. The new dependency and SDK release do not update deployed runtime images.
Platform operators must qualify and pin both versions in each runtime image.

Historical provider qualification records keep their original versions and
commit identities. This release does not retroactively qualify their runtime
images against the new package pair.
