# Marqov SDK 0.10.1

A patch release of fixes found after 0.10.0. The platform client keeps its
error contract on unreadable responses and honours the `result()` deadline,
workflow task scratch directories are removed and kept out of the shared temp
root, `NoiseModel.realistic_device` reproduces the T2 it is given, and the
CUNQA executor stops over-counting shots and validates its inputs. The README
shown on PyPI is current again.

## Install

```sh
python -m pip install --upgrade "marqov==0.10.1"
```

Python remains >=3.12. Use Python 3.12 for `[all]`, `[rigetti]` and `[pyquil]`.
Dependencies are unchanged from 0.10.0, including the `qiskit<2.6` ceiling.

## Highlights

- **Platform client.** A non-JSON response below HTTP 400 (a captive portal,
  a proxy page) raises `TransportError` instead of escaping the
  `MarqovPlatformError` hierarchy, and is never retried, so a submission is
  never sent twice. `Job.result()` caps each poll and retry at the time left
  and reports a failure after the deadline as `TimeoutError`.
  `MarqovClient` can be closed or used as a context manager.
- **Workflow tasks.** Each task's scratch directory is deleted when the task
  finishes and lives in a private per-worker directory, not the shared temp
  root.
- **Noise model.** `NoiseModel.realistic_device` no longer counts T1 twice in
  its dephasing rate; simulated coherence now decays at the requested T2.
- **CUNQA.** Extra vQPU registrations no longer multiply the shot count;
  invalid `n_qpus` and `shots` are rejected up front; a `qraise` that finishes
  after the startup timeout is torn down.
- **Reproducibility.** `LocalExecutor` records its seed in
  `metadata["reproducibility"]`, without slowing down each call.

## Upgrading

See the Upgrading section of `CHANGELOG.md` under 0.10.1. In short:

- `realistic_device` results change, and it rejects non-positive times and
  `t2 > 2 * t1`.
- `Job.result()` raises `TimeoutError` for a transport failure after its
  deadline.
- Task workdirs are deleted after the task (`MARQOV_KEEP_TASK_WORKDIR=1` keeps
  them), and background processes a task leaves in its process group are
  killed when it exits.
- Task workdirs now live in `$TMPDIR/marqov_worker_*/marqov_task_*`. A host
  cleanup script that globbed `$TMPDIR/marqov_task_*` for leftovers from killed
  workers should also sweep `marqov_worker_*` directories whose worker has
  exited.
- `CUNQAExecutor` raises `ValueError` for invalid `n_qpus`, `shots`,
  `startup_timeout_s` or `poll_interval_s`.
- An `async def` `@task` called outside a workflow must be awaited; a future
  minor release may change how direct invocation behaves.

See `CHANGELOG.md` for every entry with its pull request.
