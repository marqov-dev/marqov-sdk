# Marqov SDK 0.8.1

This is a maintenance release: provider execution fixes for IBM, Quantinuum,
IonQ and Azure, fixes to the workflow task runner, a safer retry policy in the
platform client, and general maintenance. No new public API is added. Python
remains >=3.12.

## Install

```sh
python -m pip install --upgrade "marqov==0.8.1"
```

Dependency declarations are unchanged from Marqov 0.8.0.

## Fixed

### Providers

- **IBM:** connections work again on current `qiskit-ibm-runtime`. The default
  channel is `ibm_quantum_platform`, and `instance` is optional (the service
  discovers it from the token).
  - Stored legacy values are translated, each with a `DeprecationWarning`:
    `channel="ibm_quantum"`, and a hub/group/project `instance`.
  - `MarqovDevice.run` on IBM returns counts instead of raising
    `AttributeError`.
- **Quantinuum:** circuits are measured before submission, so a run returns
  real counts instead of a single empty key.
- **IonQ:** job polling is bounded. An unrecognised terminal status raises
  instead of polling forever. A timed-out or cancelled wait issues a
  best-effort cancel of the submitted job.
- **Azure:**
  - The Cirq execution path works.
  - `MarqovDevice.run` on Azure returns integer counts keyed by bitstrings.

### Workflows

- The task runner drains the child process's stderr, so a task that writes a
  lot of output can no longer deadlock.
- The task child's result envelope is validated before use.

### Platform client

- A write whose connection failed after the request may have been sent is no
  longer retried.
  - The raised `TransportError` carries the request's idempotency key as
    `exc.idempotency_key`.
  - Transient 429, 502, 503 and 504 responses are retried for idempotent
    requests.

### CLI

- `marqov run ... --arg key=value` works again.

## Behaviour changes to know

- `IonQExecutorConfig.timeout_seconds` defaults to one hour instead of no
  timeout. Pass `timeout_seconds=None` to keep an unbounded wait.
- IBM count extraction raises a `ValueError` naming the available fields when
  a result has no readable classical register, instead of returning `{}`.
- IBM `channel="ibm_quantum"` and hub/group/project instances are deprecated
  and translated with a warning.
- `Job.cancel()` follows the write retry policy.

See the [CHANGELOG](../../CHANGELOG.md) for the full list.
