# Marqov SDK 0.7.1

This patch release fixes QiliSDK execution-option handling and adds per-call
QiliSim seeds for digital and analog sampling. Python remains >=3.12.

## Install

```sh
python -m pip install --upgrade "marqov==0.7.1" "qilisdk==0.3.0"
```

QiliSDK is installed separately; 0.3.0 is the version used in the local
qualification. Existing Braket users should retain `marqov[braket]==0.7.1`
instead of the core-only requirement above. Dependency declarations are unchanged
from Marqov 0.7.0.

## Behavior

- `execute(circuit, shots=1000, seed=42)` and
  `execute_analog(schedule, shots=1000, seed=42)` honour the seed on QiliSim.
- Seeded calls use a fresh single-threaded simulator and record both settings.
  Repeating a call on the same software/platform stack reproduces sampled counts;
  cross-version or cross-platform count equality is not promised.
- Unsupported options now raise `TypeError`. A formerly ignored keyword can
  therefore reveal a caller error after upgrading.
- Seeded QuTiP calls raise `ValueError`; unseeded QuTiP execution remains available.

See the [seed guide](../qilisdk.md) for valid seed values and examples.

## Qualification and deployment scope

The implementation passed 819 local SDK tests, including real digital and analog
QiliSim sampling and direct-backend comparison. A built wheel passed separate
sampling and option-rejection checks using the installed test dependencies.

This release does not change platform runtime pins, publish runtime images,
qualify hosted execution, or submit hardware jobs. Platform adoption remains a
separate deployment decision.

Publication status and the release tag are recorded on the
[GitHub release page](https://github.com/marqov-dev/marqov-sdk/releases/tag/v0.7.1).
